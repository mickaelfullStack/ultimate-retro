# Ultimate Retro Emulator 🎮

![Ultimate Retro Emulator Screenshot](capturar.png)

O Ultimate Retro Emulator é uma aplicação completa para emulação de consoles retro, com foco especial em PlayStation 2 (PS2). Com uma interface intuitiva e recursos avançados, oferece a melhor experiência para reviver os clássicos dos jogos retro.

## ✨ Recursos Principais

- 🕹️ Emulação de múltiplas plataformas (PS1, PS2, PSP, Nintendo, Sega, Xbox)
- 🔄 Download e instalação automática do emulador PCSX2
- 🎮 Download de jogos diretamente pela interface
- 🖥️ Suporte a tela cheia e modo janela
- 🎨 Interface moderna com animações suaves
- 📁 Gerenciamento organizado de emuladores, BIOS e jogos

## ⚙️ Pré-requisitos

- Python 3.8+
- pip
- Git (para clonar o repositório)
